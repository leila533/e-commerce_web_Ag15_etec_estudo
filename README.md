### 💪 E-commerce Web de Moda Fitness

Projeto acadêmico desenvolvido para a disciplina de **Desenvolvimento de Sistemas I**, com foco na criação de uma interface web moderna para uma loja virtual de moda fitness.

</div>

---

# ✨ Sobre o Projeto

Este projeto simula a estrutura inicial de um e-commerce fitness, apresentando produtos, banners promocionais e organização visual inspirada em lojas virtuais modernas.

O objetivo principal foi aplicar conhecimentos de desenvolvimento web, estruturação de páginas HTML e construção de layouts organizados e visualmente atrativos.

---

✔️ Trabalhar identidade visual para e-commerce
